# Retail Sales Data Analytics Dashboard | Power BI

📊 An interactive Power BI dashboard built to analyze retail sales, profitability, products, brands, regions, stores, channels, and sales trends.

## Dashboard Preview

![Retail Sales Dashboard](dashboard-image.pdf)

## Project Overview

I created this project to analyze retail sales data and build an interactive Power BI dashboard that makes business performance easier to understand.

The dashboard provides an overview of sales, orders, customers, products, profit, stores, brands, regions, cities, and sales channels. It also allows users to filter the data and explore sales performance from different perspectives.

## From Data to Dashboard

I started with retail sales data containing information about orders, customers, products, brands, stores, regions, sales channels, and financial metrics.

The data was prepared and analyzed in Power BI, followed by creating interactive visuals, KPI cards, filters, and charts to build the final dashboard.

The main goal was to create a clear and interactive report that helps users understand sales and profitability performance.

## Dashboard Pages

### Page 2 — Sales Trend Analysis

This page focuses on sales performance across different time periods.

It includes:

- Year filtering
- Month filtering
- Brand filtering
- Region filtering
- City filtering
